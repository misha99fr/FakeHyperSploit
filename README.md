# FakeHyperSploit 🚀

> Смешная пародия на оригинальный [HyperSploit](https://github.com/TheAirBlow/HyperSploit) что имитирует разблокирование бутлоадера с абсолютно поддельными (и смешными) сообщениями!

## 🤣 Что это?

Это **шуточный проект** что имитирует поведение вистинского инструмента HyperSploit, но вместо того чтобы сделать что-то полезное, он просто печатает смешные поддельные сообщения и притворяется что разблокирует бутлоадер вашего телефона самыми абсурдными способами.

**ВНИМАНИЕ: Это АБСОЛЮТНО НЕ ДЕЛАЕТ НИЧЕГО. Это 100% поддельно. Не используйте это для разблокирования вашего телефона!**

## Особенности

✨ **Абсолютно поддельно но забавно:**
- Поддельная детекция устройства (результаты могут различаться)
- Имитируемая проверка версии HyperOS
- Детекция SIM карты на квантовой основе
- Отключение интернета используя интерпретативный танец
- Запросы привязки сваренные с квантовой механикой
- Состояния бутлоадера что существуют только в параллельных вселенных
- Смешные предупреждения о побочных эффектах
- Анимации загрузки что ведут в никуда

## 🎯 Как использовать

### Требования
- Python 3.6+
- Чувство юмора
- Абсолютно БЕЗ настоящего телефона

### Установка

```bash
git clone https://github.com/misha99fr/FakeHyperSploit.git
cd FakeHyperSploit
chmod +x fakehypersploit.py
```

### Запуск

```bash
python3 fakehypersploit.py
```

Или на Unix-подобных системах:

```bash
./fakehypersploit.py
```
